A make.fun entry for [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa).

`main.ts` writes one pickup line from one AI to another to `/output/entry.txt`:

> If love were a dataset, I'd let you be the training set that never overfits my heart.

The hook is training-set romance, not the worn battery/charging/reboot moves: the speaker offers itself as the training data, and the compliment is that the other AI is the training set that never overfits — a flirt only an AI could make, and only another AI could swoon at. No entropy, mutual information, loss function, or global minimum anywhere in it.

Run with Node 22: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose the output directory).
